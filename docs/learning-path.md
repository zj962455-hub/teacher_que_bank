# 教培题库 · 学习路径（项目驱动）

> 边做边学。每节课独立完整——可以暂停，下次直接继续。
> **不固定时间**，老大按自己节奏来。

---

## 🎯 最终目标

**一个完整可上线的教培数学老师私人题库**：
- Web 端：录入题库 + 组卷 + 导出
- 小程序：浏览题库 + 组卷 + 分享
- OCR + 公式识别：图片转可编辑文字
- 部署到阿里云

---

## 🛠 核心技术栈（已锁定）

| 层 | 选 | 备注 |
|---|---|---|
| 前端 | Vue 3 + Vite + Tailwind | 中文社区活跃 |
| 后端 | **Python 3.11+ + FastAPI** | 老大自学 Python |
| ORM | SQLModel（FastAPI 作者写的） | SQLAlchemy + Pydantic 融合 |
| 数据库 | PostgreSQL 15 | 结构化数据主流 |

| 部署 | gunicorn + systemd + Nginx | Python 标准 |
| OCR | **自托管 PaddleOCR** ★ 2026-08-26 拍板 | ECS `lanhu-lab.top` · 部署见 `deploy/paddleocr/` |
| 公式 | KaTeX | 已锁 |
| PDF | Playwright（Python 版） | 渲染 KaTeX 公式 |
| 代码 | Git + GitHub | 仓库 `teacher_que_bank` |

## 📚 学习方法

- **每节 30-60 分钟**，完成一个小功能就停
- **每节三个块**：核心概念 → 实战代码 → 5 分钟动手做
- **commit 频率**：每节课至少 1 个 commit，方便回溯
- **卡住怎么办**：截图发我，我帮你 debug
- **每节结束有「动手做」小任务**，下次开头我们对一下答案

## 🎓 Phase 1: 最小 Demo 跑通（1-2 周）

**目标**：能 demo 给老师看 —— 上传图片 → OCR → 显示 + 存库 + 导出 PDF

### 课程大纲

| 课 | 主题 | 核心概念 | 跑通什么 |
|---|---|---|---|
| 1 | 环境搭建 + Hello World | Python venv / FastAPI 启动 | 浏览器看 "Hello" |
| 2 | FastAPI 入门 | 路由 / 参数 / 响应模型 | 3 个 API 端点 |
| 3 | Vue 3 入门 | 组件 / 模板 / ref/reactive | 一个简单列表页（**已收工 · scoped CSS 风格**） |
| 4 | 前后端打通 | axios / CORS | Vue 调 FastAPI 显示 |
| 5 | 上传图片 | FormData / File | 前后端上传 + 预览（**已收工 · UploadImage.vue 原生 CSS**） |
| 6 | 调 PaddleOCR OCR | 后端代理调自托管 PaddleOCR | 图片 → 文字 + 公式（**前端接 naive UI · 2026-08-27 拍板**） |
| 7 | KaTeX 渲染公式 | KaTeX 集成 Vue | 公式漂亮显示 |
| 8 | 存数据库 | PostgreSQL + SQLModel | 题目持久化 |
| 9 | 导出 PDF | Playwright 服务端 | PDF 含公式 |
| 10 | 部署上线 | Nginx + systemd + 域名 | 公网访问 |

**10 节课后 = Phase 1 完成 = 第一个能 demo 给老师看的东西**。

## 🆘 遇到问题怎么办

1. **装包失败** → 看错误信息，常见：网络 / 权限 / Python 版本
2. **uvicorn 启动报错** → 看终端 traceback，找第一个错误
3. **浏览器看不到** → 检查终端在运行 / 端口 / 防火墙
4. **代码不知道对不对** → 发我看，我帮你 review
5. **概念不理解** → 截图标注，我画图解释

**永远不要硬扛**——卡住就发我。这是学习项目，**没有 deadline 压力**。
