### 课 33 · 性能优化的设计取舍（2026-11-06 落地时定的）

| 决定 | 理由 |
|---|---|
| **列表接口不带 `blocks`** | `blocks` 是 OCR 原始识别块（每块带 bbox），单题最多 50 KB。列表页根本不用它，只有 OCR 校对页 / 详情页要 —— 50 道题白下 165 KB |
| **详情接口仍然带 `blocks`** | OCR 溯源要靠它。列表省、详情不省，两头不打架 |
| **COUNT 交给数据库，不在 Python 里 `len(all())`** | 题库几千道时，`len(session.exec(select(...)).all())` 就是「把整表拉进内存再扔掉」 |
| **N+1 改成批量查** | 试卷列表的题目数用一条 `GROUP BY`；试卷详情的题目用一条 `IN (...)` —— N+1 次往返压成 1 次 |
| **组合索引 + pg_trgm** | 真实查询几乎都是「按 user_id 过滤 + 按某字段排序」，单列索引省不掉 Sort 节点；关键词 `ILIKE '%x%'` 只有 trigram 能吃住 |
| **前端首屏少一次请求**：扁平分类从树推导 | `/api/categories/`（树）和 `/api/categories/flat`（扁平）数据完全重叠，树节点本来就带 `parent_id` —— 扁平直接从树推 |
| **vue-devtools 只在 dev 模式挂** | 生产包里混进了 devtools 客户端代码，线上没人用，纯属白下 |
| **不手动拆 chunk** | 试过把 vue / katex 手动拆成独立 chunk，rolldown 把一堆依赖卷进去，首屏 JS 从 555 KB 涨到 1002 KB。交给 rollup 按动态 import 边界自己分 |

### 课 32 · 错误处理 + Loading 的设计取舍（2026-11-06 落地时定的）

| 决定 | 理由 |
|---|---|
| **所有错误返回同一形状** `{detail, code, request_id}` | 之前三个异常出口各写各的，前端每页写一遍解析，漏一处就一处白屏 |
| **`detail` 永远是字符串** | 旧的开发模式 422 返回数组 → 前端 `{{ data.detail }}` 渲染成空白 |
| **`code` 是稳定机器码** | 前端按 code 分支（auth.expired 跳登录），不猜中文文案 |
| **`request_id` 每个错误都有** | 老师截图报错时 id 就在界面上，运维直接搜日志；`X-Request-ID` 响应头同步 |
| **前端 `parseError()` 收口** | 网络断了显示「连不上服务器」而不是「Network Error」；反代返 HTML 也要兜住 |
| **`useAsyncTask` + `TaskState` 两件套** | loading / 出错+重试 / 空 三态不再每页各写一遍 |
| **失败后能原地重试** | 之前只能刷新整页 |

### 分享链接的设计取舍（课 24 · 2026-11-05 落地时定的）

| 决定 | 理由 |
|---|---|
| **公开接口不用登录** | 分享的意义就是「对方没账号也能看」；要对方先注册，功能就没意义了 |
| **token 明文存** | 老师要能反复复制**同一个**链接（这周班级群、下周补课群）；存哈希就永远拿不回原文。泄露面也小：只值一张卷的只读 + 限时 + 可吊销 |
| **必带过期时间**（默认 7 天，上限 30 天） | 链接发出去就收不回来（可能已进群存档、已转发第三方）。没有「永久链接」这个选项 |
| **过期 / 吊销一律 404，不区分原因** | 区分了等于告诉访问者「这个链接曾经存在」 |
| **公开返回体不含任何用户字段** | 分享接口是唯一对外暴露题目内容的口子，不吐 owner id / 用户名 |
| **每次访问记 view_count / last_viewed_at** | 备案要求记录访问日志；这条链接是唯一一条对外口子 |
| **删卷 / 删号 → 链接级联消失** | FK ON DELETE CASCADE；否则链接还在却打不开，还占着一条指向空卷的记录 |

## 🆘 遇到问题怎么办

1. **装包失败** → 看错误信息，常见：网络 / 权限 / Python 版本
2. **uvicorn 启动报错** → 看终端 traceback，找第一个错误
3. **浏览器看不到** → 检查终端在运行 / 端口 / 防火墙
4. **代码不知道对不对** → 发我看，我帮你 review
5. **概念不理解** → 截图标注，我画图解释

**永远不要硬扛**——卡住就发我。这是学习项目，**没有 deadline 压力**。
