## 这是什么

面向 **教培数学老师** 的 **私人题库 + 轻量组卷工具** 的 MVP 原型（低保真线框图）。

## 核心用户场景

- **用户**：教培数学老师（一群，老大身边的人）
- **痛点**：自己设计的题散落在 Word / 网盘 / 纸质，没有方便管理 + 组卷的工具
- **方案**：Web 录入题库 + 小程序辅助浏览/组卷 + 一键导出 PDF/JPG

## 关键设计决策（已锁定）

| 决策点 | 选择 | 理由 |
|---|---|---|
| 录题主战场 | Web 端 | 富文本 + 图片录入体验最好 |
| 题目分类 | 章节树 + 自由标签 | 数学老师天然习惯 |
| 组卷模式 | 自由勾选 + 自动排序 | MVP 先轻量 |
| 导出格式 | PDF + JPG | DOC 排版复杂先不做 |
| 题目可见范围 | 默认仅自己 | 符合「私人题库」定位 |
| 商业模式 | 暂未启用 | 先跑通用户量再加付费墙 |
| 题干编辑器 | 富文本（Markdown 基础） | 不做公式编辑器 |
| 分类层级 | 两级（章 → 小节） | 路径字符串存储，扩展不改库 |
| **图片录入** | **OCR 自动识别（Mathpix）** | **v0.2 新增：图片 → 文字 + 公式自动转换** |
| **公式处理** | **LaTeX 源码 + KaTeX 渲染** | **v0.2 新增：数学公式可编辑、可识别** |
| **OCR 触发** | **上传后自动** | **节省操作，但要明确告知老师可校对** |
| **原图保留** | **是** | **OCR 文字后保留原图，作为校对参考** |

## 技术选型（已定核心 · 其余待定）

### 已锁定

- **公式识别 OCR**：**Mathpix API**（业界标准）
  - 价格：$4.99/月包 1000 次，pay-as-you-go $0.004/题
  - 准确率：印刷体 90%+，手写体 70-80%
  - 成本承担：MVP 阶段项目方出（月 ¥35 几乎可忽略）
- **公式渲染**：**KaTeX**（前端库）
  - 速度快、轻量、MathJax 的现代替代品
  - 支持 LaTeX 数学公式完整语法

### 待定

- **前端 Web**：Vue 3 / React + Vite + TailwindCSS
- **小程序端**：uni-app（一份代码多端） 或 原生微信小程序
- **后端**：Node.js (NestJS) 或 Python (FastAPI)
- **数据库**：PostgreSQL（题库 + 试卷） + 阿里云 OSS（图片）
- **PDF 生成**：服务端用 Puppeteer（HTML → PDF）或 jsPDF（前端）

## 🆕 v0.2 新增：OCR + 公式识别流程

```
老师上传图片（拍照/扫描/截图）
        ↓
服务端调 Mathpix API
        ↓
返回：题干文字 + 公式 LaTeX 代码
        ↓
富文本框自动填入 + KaTeX 渲染公式
        ↓
原图保留作为校对参考
        ↓
老师对照原图校对、必要时手动改
        ↓
发布（HTML + LaTeX 结构化存储）
```

**准确率预期**：
- 印刷体（教科书/试卷扫描）：90%+ ✅
- 老师手写题：70-80% ⚠️
- 复杂图文混排：60-70%

**为什么不直接 100% 准就不校对**：
- OCR 没法 100% 准
- 公式识别可能把 n₂ 识别成 n²（手写体常见）
- 老师校对是最后一道把关，**可发布前必看**

**成本估算（50 个老师）**：
- 50 老师 × 每月 20 题 × 50% 图片题 = 500 次/月
- 月成本：**$4.99 ≈ ¥35**
