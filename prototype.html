📌 MVP 录入设计决策（v0.2 已升级）
  • 双录入模式：📷 图片识别 / ✏️ 手动录入 —— 老大的需求场景里 80% 是图片题（教科书/试卷扫描/截图）
  • OCR 服务：Mathpix API（业界标准）—— 印刷体准确率 90%+，手写体 70-80%
  • 公式识别：OCR 自动提取 LaTeX 代码，前端用 KaTeX 渲染（快、轻、现代主流方案）
  • 原图保留：OCR 提取文字后原图保留作为校对参考，老师可对照原图改文字
  • 识别结果可编辑：老师校对 → 直接编辑 → 发布，所有内容结构化存储（HTML + LaTeX 片段）
  • 公式工具栏 ∑ 按钮：手动插入 LaTeX 公式入口（不依赖图片也能输公式）
  • 准确率预估显示：识别完成显示预估准确率，老师心理有数
  • 答案 / 解析也支持 OCR：题干和答案可以分别 OCR 处理
  • 分类用树状下拉，右侧固定 300px 栏方便快速切换
  • 自动保存草稿（每 30 秒），避免老师写一半丢失
  • 可见范围默认仅自己，符合「私人题库」定位

高一 数列 等差 求和 ★★★ 解答题
已知等差数列 {aₙ} 的前 n 项和为：

Sₙ = n² + n

求该数列的通项公式 aₙ。
[题目配图]
答案 / 解析
∵ Sₙ = n² + n
∴ a₁ = S₁ = 1² + 1 = 2
当 n ≥ 2 时：aₙ = Sₙ - Sₙ₋₁
        = (n² + n) - ((n-1)² + (n-1))
        = 2n
验证 a₁ = 2(1) = 2 ✓
∴ aₙ = 2n
